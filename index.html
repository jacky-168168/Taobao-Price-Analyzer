③ 匯入歷史價格

從價格歷史服務取得資料後，一行貼一筆。格式：日期,價格。例如：2026-10-01,469

也支援 CSV 欄位：date,paid_price,list_price,source,note。不同價格口徑不混為同一條線。

查詢外部歷史價格

第三方網站需自行貼上連結查詢。網站不會讀取別人的購物車或已登入帳號。

自動追蹤與同步

GitHub Actions 執行後會將歷史參考報價寫入 data/provider_history.json。本機新增的商品不會自動新增 GitHub 監控清單，請複製 JSON 並更新 config/watchlist.json。API 金鑰不得放在網站中。

歷史紀錄與資料備份

下表僅是你儲存在此瀏覽器的紀錄；第三方參考報價另外顯示且不會替換實付價。同來源、同日期再次匯入會更新。跨裝置請匯出／還原備份。

本工具為個人價格紀錄分析，無淘寶或第三方數據服務官方授權。所有「最低價」均僅指已收集、相同 SKU、相同價格口徑的觀測資料。
